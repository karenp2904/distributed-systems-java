# distributed-systems-java
# Distributed Systems - Java

Este repositorio contiene las prácticas y proyectos desarrollados en el curso de **Sistemas Distribuidos**, implementados en **Java**.  
Cada carpeta corresponde a un laboratorio o proyecto que cubre diferentes conceptos de comunicación distribuida, concurrencia y servicios.

---

## 📂 Contenido

| Carpeta / Proyecto        | Descripción |
|--------------------------|-------------|
| **clienteInventario**    | Cliente para el sistema de inventario, diseñado para conectarse a un servidor y gestionar productos en un entorno distribuido. |
| **Lab_FilesToPdf**       | Laboratorio que convierte archivos en diferentes formatos a PDF utilizando técnicas de procesamiento distribuido. |
| **Lab_UrlToPdf**         | Laboratorio para convertir contenido obtenido desde una URL en un documento PDF de forma automatizada. |
| **Lab01_InterfacesJava** | Primer laboratorio: introducción a las interfaces en Java, preparando la base para proyectos distribuidos. |
| **Lab02_Sockets-Songs**  | Implementación de comunicación cliente-servidor usando **Sockets**, enviando información relacionada con canciones. |
| **Lab03_RMI-Songs**      | Laboratorio con **Java RMI (Remote Method Invocation)** para invocar métodos de forma remota y trabajar con objetos distribuidos. |
| **Lab07_FileToPdf**      | Proyecto que recibe archivos a través de la red y los convierte a PDF en un servidor, aplicando conceptos de distribución. |
| **Lab08_SOAP**           | Proyecto con **Web Services SOAP**, demostrando el consumo e implementación de servicios web. |

---

## 🛠️ Tecnologías Usadas
- **Java 8+**
- **Sockets**
- **Java RMI**
- **SOAP Web Services**
- **iText / PDFBox** (para generación de PDFs)
